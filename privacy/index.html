Privacy policy: The Living Ledger publishing tool

Last updated: 8 October 2026

This policy covers the private software tool that the owner of the YouTube channel The Living Ledger uses to publish the channel's own videos. The tool is not offered to anyone else.

What the tool accesses

  • YouTube (Google OAuth): the tool uploads the channel's own videos and sets their titles, descriptions, tags, thumbnails, caption tracks and publishing schedule. It reads the processing status of those videos. If granted, it also reads the channel's own analytics (read-only).
  • Google Drive (Google OAuth, drive.file scope only): the tool stores backups of the channel's own episode files and the public "sources and credits" pages it creates. It cannot see any other files in the owner's Drive.

What the tool does not do

  • It does not access other users' channels, accounts or data.
  • It does not collect personal information about viewers.
  • It does not post comments, like or subscribe, or send messages.
  • It does not sell, share or transfer any data to third parties.

Storage and security

OAuth tokens are stored only on the owner's own computer, in files that are not shared or published. The owner can revoke access at any time at https://myaccount.google.com/permissions.

Use of YouTube API Services

The tool uses the YouTube API Services. By using it, the owner agrees to the YouTube Terms of Service (https://www.youtube.com/t/terms) and the Google Privacy Policy (https://policies.google.com/privacy).

Contact

The channel owner, via the contact details on The Living Ledger's YouTube "About" page.
